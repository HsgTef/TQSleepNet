# TQSleepNet

Official implementation of "TQSleepNet: Multi-Scale Temporal-Token Query
Network with Shared Cross-Modal Attention for Sleep Staging".

The model is defined in `TQSleepNet_Ablation_module_TNSRE.py` (PyTorch).
Pretrained weights and the full training/evaluation pipeline will be
added after publication.
